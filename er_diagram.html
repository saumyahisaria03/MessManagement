Cardinality Explanations
Hostel → Students (1 : N)

Each student belongs to exactly one hostel block, while a hostel houses multiple students.

Students ↔ Messes (M : N via Subscriptions)

Resolved by junction table student_mess_subscriptions with subscription start and end dates.

Attendance Swipes (1 : N)

Every swipe records student ID, mess ID, meal slot (Breakfast/Lunch/Dinner), and exact timestamp.

Rebates & Billing (1 : N)

Approved leaves automatically calculate rebate deductions per day against monthly base fees.
