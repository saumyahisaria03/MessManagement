MAPPING OF USER REQUIREMENTS
Requested Attributes in STUDENT Entity:
  • Name: Composite attribute (First_Name + Last_Name).
  • Registration number: Primary key (solid underline).
  • Room number: Simple attribute Room_No (linked to Hostel).
  • Veg / Non-Veg Food: Dietary preference attribute (Veg, Non-Veg, Jain, Egg).
WEAK ENTITIES & DERIVED ATTRIBUTES

1. MESS_REBATE (Weak Entity)
Identified by strong entity STUDENT via double diamond APPLIES_FOR. Partial key: Rebate_No (dashed underline).
Derived Attribute: Leave_Days = (End_Date - Start_Date + 1).

2. MONTHLY_BILL (Weak Entity)
Identified via double diamond GENERATED_FOR. Partial key: Billing_Month.
Derived Attributes: Rebate_Discount and Net_Payable (Base - Rebate + Extras).
